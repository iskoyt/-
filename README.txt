КУБИК — УЧЕБНЫЙ МАГАЗИН ИГРУШЕК

ЗАПУСК
1. Распакуйте архив.
2. Оставьте index.html и style.css в одной папке.
3. Откройте index.html двойным щелчком в браузере.
Интернет, сервер и установка библиотек не нужны.

СОДЕРЖИМОЕ
index.html — структура и текст страницы.
style.css — оформление и адаптация для телефонов.
Каждая строка HTML и CSS содержит пояснение после кода.
HTML-комментарии: <!-- пояснение -->. CSS-комментарии: /* пояснение */.

ВОЗМОЖНОСТИ
Каталог из шести товаров, фильтр по категориям без JavaScript,
навигация по разделам, ссылка на электронную почту, адаптивная сетка.
Клавиатура: Tab для перехода между элементами, стрелки для категорий.

ЧТО ИЗМЕНИТЬ
В index.html замените названия, цены и демонстрационный адрес
hello@example.com в почтовой ссылке и подписи на свой настоящий адрес.
В style.css измените переменные в блоке :root для настройки цветов.
Изображения представлены системными эмодзи; их вид зависит от устройства.
Возрастные отметки, цены и ассортимент — учебные примеры.

ГРАНИЦЫ ПРОЕКТА
Это готовая статическая витрина на HTML и CSS. Корзина, хранение заказов,
оплата и отправка формы не реализованы. Ссылки «Заказать» ведут к контактам,
а почтовая ссылка открывает настроенное почтовое приложение.
Для настоящих онлайн-заказов понадобится сервер или внешний сервис.
